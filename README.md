# GradXen-master-releases
Downloads for GradXen Master, the staff app for GradXen (for professors, invigilators and administrators)
1. Get the latest installer from Releases on the right. Installed copies update themselves.
2. After your download, run this on your Windows PC and install the GradXen master app.
3. After installing successfully - The first time, you need to open the client app and create an account using the email that your admin registered on GradXen for you. You will need either of Google Authenticator or Microsoft Authenticator on your smartphone to enable 2-factor authentication for your account.
4. Once you have registered, you can always log in using the same email-password combination plus the authenticator code.

@Students: This isn't your app. Please use the link your professor gave you.
